
## 제4회 ETRI 휴먼이해 인공지능 논문경진대회

주관: 한국전자통신연구원(ETRI)  
운영: 데이콘  
성과: Private Leaderboard 기준 상위 9.5% (35 / 370팀)  

---
## 📰 대회 개요

본 대회는 ETRI에서 공개한 라이프로그(Lifelog) 데이터셋을 활용하여
인간의 일상 행동, 수면 상태, 심리적 요인을 이해하고 예측하는 연구형 인공지능 경진대회이다.

라이프로그 기반 인간 이해를 주제로 한 연구 중심 대회로,
대학원 연구자(석·박사 과정)의 참여 비중이 높은 경쟁 환경에서 진행되었다.

이러한 환경 속에서 **Private Leaderboard 기준 상위 9.5%** 의 성과를 달성하였다.

---
## 📰 데이터셋 설명 (ETRI Lifelog Dataset)

본 연구에서는 ETRI가 2024년에 공개한 라이프로그 데이터셋을 사용하였다.   [데이터 링크](https://dacon.io/competitions/official/236468/overview/description)  

해당 데이터셋은 스마트폰, 스마트워치, 수면 센서 및 자가 보고 애플리케이션을 활용하여 12주 동안 50명의 참가자로부터 수집된 실제 생활 기반 데이터로 구성되어 있다.  
총 약 700일 분량의 라이프로그 기록이 포함되어 있으며, 일상 활동, 환경 정보, 생체 신호 및 수면 행동을 포괄적으로 반영하는 멀티모달 센서 데이터셋이다.

수집된 주요 데이터 항목(멀티모달)은 다음과 같다.

| 데이터 항목 | 구분 | 설명 |
|-----------|----|------|
| mActivity | 스마트폰 | Google Activity Recognition API 기반 사용자 활동 정보 |
| mScreenStatus | 스마트폰 | 스마트폰 화면 사용 여부 |
| mUsageStats | 스마트폰 | 스마트폰 앱 사용 통계 (사용 앱 및 사용 시간) |

## 📰 예측 대상 지표 (Prediction Targets)

본 연구에서는 수면 건강, 피로도 및 스트레스 상태를 예측하기 위해  
수면 센서 데이터와 자가 보고 설문 기록을 기반으로 총 **6개의 지표(Q1–Q3, S1–S3)** 를 정의하였다.

각 지표는 **이진 분류(2단계)** 또는 **다중 분류(3단계)** 문제로 구성되며,  
지표별 세부 분류 기준은 대회 측에서 제공한 기준 문서를 따른다.

---
### 1) 주관적 설문 지표 (Survey-based Metrics)

주관적 설문 지표는 개인이 인지한 상태를 **개인 평균 대비 상대적 수준**으로 평가한다.

| 지표 | 설명 | 라벨 값 | 의미 |
|----|----|----|----|
| Q1 | 기상 직후 인지한 전반적인 수면의 질 | 0<br>1 | 0: 개인 평균보다 수면의 질이 낮다고 인지<br>1: 개인 평균보다 수면의 질이 높다고 인지 |
| Q2 | 취침 직전 인지한 신체적 피로도 | 0<br>1 | 0: 피로도가 개인 평균보다 높음<br>1: 피로도가 개인 평균보다 낮음 |
| Q3 | 수면 직전 인지한 스트레스 수준 | 0<br>1 | 0: 스트레스 수준이 개인 평균보다 높음<br>1: 스트레스 수준이 개인 평균보다 낮음 |

**Q1–Q3는 개인 평균을 기준으로 한 이진 분류 문제**로 정의된다.


### 2) 객관적 수면 지표 (Sleep Sensor-based Metrics)

객관적 수면 지표는 수면 센서로 측정된 값이  
국제 수면 가이드라인을 **충족하는지 여부**에 따라 라벨링된다.

| 지표 | 설명 | 라벨 값 | 의미 |
|----|----|----|----|
| S1 | 총 수면 시간(TST) 지침 준수 여부 | 0<br>1<br>2 | 0: 권장 수면 시간 미달<br>1: 권장 수면 시간에 근접<br>2: 권장 수면 시간 충족 |
| S2 | 수면 효율(SE) 지침 준수 여부 | 0<br>1 | 0: 수면 효율 기준 미달<br>1: 수면 효율 기준 충족 |
| S3 | 수면 시작 잠복기(SOL) 지침 준수 여부 | 0<br>1 | 0: 잠드는 데 시간이 오래 걸림<br>1: 잠드는 데 걸리는 시간이 기준 이내 |

**S1은 3단계 분류**, **S2·S3는 이진 분류 문제**로 정의된다.

---

### 📰 라벨 예시 설명

예를 들어, 한 참가자가  
- 기상 직후 “어제 잠을 잘 잤다”고 인지했다면 **Q1 = 1**,  
- 취침 전 피로와 스트레스를 크게 느꼈다면 **Q2 = 0, Q3 = 0**으로 라벨링된다.

또한 수면 센서 분석 결과  
- 총 수면 시간이 권장 기준에 미치지 못하면 **S1 = 0**,  
- 수면 효율과 수면 잠복기가 기준을 충족하면 **S2 = 1, S3 = 1**로 정의된다.

본 프로젝트에서는 이러한 **주관적·객관적 지표를 동시에 예측하는 멀티태스크 분류 문제**로 접근하였다.

## 📰 평가 방식

평가지표: **Macro F1-Score**  
  
<img width="562" height="52" alt="image" src="https://github.com/user-attachments/assets/6dfa7742-6a84-42ca-b0fb-708117f8d5d6" />

본 대회는 6개 예측 지표(Q1–Q3, S1–S3)에 대해 각각 Macro F1-score를 산출한 뒤, 이들의 평균을 최종 점수로 사용하는 방식으로 평가된다.

Public Leaderboard는 전체 테스트 데이터의 44%를 사용하여 모델 성능에 대한 피드백을 제공하며, 최종 순위는 전체 테스트 데이터를 사용한 Private Leaderboard 점수를 기준으로 산정된다.
